# 博客系统产品需求文档（PRD）

> 版本：v1.0  
> 定位：开源演示项目的首版产品需求

## 1. 产品概述

本产品是一个支持多位博主写作的博客系统。访客可以浏览和搜索文章；注册用户可以收藏和评论；博主可以发布带图片的文章；管理员负责博主权限和全站内容管理。

项目用于展示一个完整软件产品的建设过程。观众可获取公开的项目资料，并按说明快速体验主要功能。本版不以对外正式运营为目标。

本文件只规定产品行为和验收标准，不规定实现方式。

## 2. 产品目标与完成标准

| 目标 | 完成标准 |
| --- | --- |
| 内容发布 | 至少两位博主可以分别完成创建草稿、预览、发布、修改、下线、删除和恢复文章；双方不能修改彼此的文章。 |
| 内容发现 | 访客可以浏览公开文章，按关键词搜索，按标签查找，并阅读图文内容。 |
| 用户参与 | 用户可以注册、登录、收藏文章和发表评论；访客阅读文章无需注册。 |
| 权限管理 | 管理员可以授予和撤销博主权限，并管理全站文章、标签和评论。 |
| 项目体验 | 第一次接触项目的观众按公开说明执行一次启动操作后，可以完整体验上述流程。 |

## 3. 用户角色与权限

| 操作 | 访客 | 注册用户 | 博主 | 管理员 |
| --- | :---: | :---: | :---: | :---: |
| 阅读、搜索公开文章 | ✓ | ✓ | ✓ | ✓ |
| 收藏文章、管理自己的收藏 |  | ✓ | ✓ | ✓ |
| 发表评论、删除自己的评论 |  | ✓ | ✓ | ✓ |
| 创建和管理自己的文章 |  |  | ✓ | ✓ |
| 删除自己文章下的评论 |  |  | ✓ | ✓ |
| 管理全站文章、标签和评论 |  |  |  | ✓ |
| 授予或撤销博主权限 |  |  |  | ✓ |

一个账号使用同一套登录入口。新注册账号默认为普通用户；只有管理员可以授予博主权限。管理员也可以写文章，创建的文章署名为该管理员。撤销博主权限后，账号仍是普通用户，其既有文章和署名保留，由管理员继续管理；重新授权后，该博主恢复对自己文章的管理权。

## 4. 首版产品范围

首版包含：文章列表与详情、搜索、标签、注册和登录、收藏、评论、多博主内容管理、文章图片、文章回收站、管理员权限管理，以及用于观众体验的示例内容和指引。

首版不包含分类、多人同时编辑同一篇文章、评论回复或楼中楼、邮箱验证、密码找回、定时发布、付费内容、推荐算法、社交关系和对外正式运营所需的运营功能。

## 5. 功能需求

### 5.1 公开阅读

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 文章列表 | 首页只展示已发布文章，按最近发布时间倒序排列；每篇显示标题、摘要、作者、发布时间和标签；文章较多时可翻页。 |
| FR-02 | 文章详情 | 详情展示标题、作者、发布时间、正文、标签、收藏状态和评论；正文中的标题、列表、引用、代码和图片可正常阅读。 |
| FR-03 | 关键词搜索 | 关键词可匹配已发布文章的标题、摘要和正文；结果只包含公开文章；无结果时有明确提示。 |
| FR-04 | 标签浏览 | 点击标签可查看使用该标签的已发布文章；一个文章可有多个标签；无结果时有明确提示。 |
| FR-05 | 不可访问内容 | 草稿、已下线和回收站中的文章不出现在列表、搜索或标签结果中；直接打开其地址或无效地址时显示“文章不存在或暂不可访问”。 |
| FR-06 | 多设备阅读 | 在常见手机和桌面宽度下，导航、列表、正文、图片和评论均可使用；长代码块不会遮挡其他内容。 |

### 5.2 账号与权限

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-07 | 用户注册 | 访客使用邮箱、昵称和密码注册；邮箱不区分大小写且不能重复；密码至少 8 位，需再次输入确认；缺失或无效输入有明确提示；注册成功后成为已登录的普通用户。 |
| FR-08 | 登录与退出 | 用户用邮箱和密码登录；凭据错误时得到明确但不暴露账号是否存在的提示；退出后不能继续使用需登录的功能。 |
| FR-09 | 角色访问 | 普通用户不能进入文章和权限管理页面，也不能执行管理操作；博主只能管理自己的文章；管理员能管理全站内容。 |
| FR-10 | 博主授权 | 管理员可以从注册用户中选择账号授予或撤销博主权限；操作结果立即生效；普通用户不能自行获得该权限。 |

### 5.3 收藏与评论

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-11 | 收藏文章 | 已登录用户可在已发布文章详情页收藏或取消收藏；操作后状态立即更新，同一篇文章不会重复出现在个人收藏中；访客点击收藏入口时被引导登录。 |
| FR-12 | 我的收藏 | 用户可查看自己的收藏列表、打开文章或取消收藏；列表为空时有提示；任何用户都不能查看他人的收藏。 |
| FR-13 | 发表评论 | 已登录用户可在已发布文章下发表纯文字评论；空白评论不能提交，单条最多 1000 个字符；发表成功后显示评论者昵称和时间；访客点击评论入口时被引导登录。 |
| FR-14 | 删除评论 | 用户可删除自己的评论；博主可删除自己文章下的评论；管理员可删除全站评论。删除前需确认，删除后评论不再展示且不能恢复。其他用户不能执行删除。 |

### 5.4 博主写作与文章管理

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-15 | 文章管理列表 | 博主能查看自己全部未删除文章的标题、状态、最近修改时间，并按状态筛选；管理员能查看全站文章及作者。 |
| FR-16 | 创建和编辑 | 博主可填写标题、摘要、正文并选择现有标签；新文章默认保存为草稿；标题和正文必填；保存成功或失败都有明确反馈。 |
| FR-17 | 文章作者 | 文章显示创建者的署名；博主不能修改作者或编辑其他博主的文章；管理员可编辑全站文章，编辑不会改变原署名。 |
| FR-18 | 图片上传 | 博主可上传 JPG、PNG 或 WebP 图片并插入文章正文；单张不超过 10 MB；上传失败、格式不支持或超出大小限制时给出具体提示；预览及公开详情能正确显示图片。 |
| FR-19 | 预览 | 博主可预览自己的草稿、已发布和已下线文章；预览呈现读者将看到的图文效果，不改变公开状态；除文章作者与管理员外，其他人不能查看预览。 |
| FR-20 | 发布与修改 | 标题和正文完整的草稿可以发布；发布后文章出现在公开列表、搜索和标签结果中；修改已发布文章并保存后，读者看到更新内容。 |
| FR-21 | 下线与再次发布 | 博主可下线自己的已发布文章；下线后读者不可访问，博主仍可编辑；再次发布后重新公开。 |
| FR-22 | 删除与恢复 | 删除文章前需确认；删除后文章进入回收站并停止公开；博主可恢复自己的文章，管理员可恢复全站文章；恢复后回到删除前的状态，正文、图片、标签和原有评论均保留。 |
| FR-23 | 文章访问地址 | 每篇文章有稳定的访问地址；修改标题、下线或恢复文章不改变该地址。 |

### 5.5 管理员内容管理

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-24 | 标签管理 | 管理员可新增、改名和删除标签；标签名不能重复；删除已被文章使用的标签前须提示影响，确认后从相关文章移除该标签。博主只能为文章选择现有标签。 |
| FR-25 | 全站文章管理 | 管理员可查看、编辑、发布、下线、删除和恢复任意博主的文章；这些操作不改变文章作者署名。 |
| FR-26 | 全站评论管理 | 管理员可在文章详情或管理页面查看并删除任意评论；删除后评论不再对读者展示。 |

### 5.6 项目体验

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| FR-27 | 示例内容 | 首次体验时可看到至少 3 篇来自至少 2 位博主的示例文章，覆盖图文、不同标签及可搜索内容；公开页面只显示已发布文章。 |
| FR-28 | 体验指引 | 公开说明使观众能够进入读者页面和管理页面，了解体验账号，完成注册、收藏、评论、博主授权、写稿、上传图片、发布、下线、删除和恢复。 |
| FR-29 | 快速体验 | 观众按公开说明执行一次启动操作后，无需另行申请第三方账号或准备私有资料，即可体验 FR-27 和 FR-28 所述流程。 |

## 6. 核心业务规则

### 6.1 文章状态

| 当前状态 | 可执行操作 | 操作结果 |
| --- | --- | --- |
| 新建 | 保存 | 草稿 |
| 草稿 | 发布、删除 | 已发布、回收站 |
| 已发布 | 修改、下线、删除 | 已发布、已下线、回收站 |
| 已下线 | 修改、再次发布、删除 | 已下线、已发布、回收站 |
| 回收站 | 恢复 | 删除前的状态 |

只有已发布文章对读者公开。文章删除后保留在回收站，首版不提供彻底删除。恢复到“已发布”状态的文章会重新公开。每次从草稿或已下线状态发布时，公开列表以该次发布时间排序；从回收站恢复不会改变原发布时间。

### 6.2 收藏、评论与图片

1. 文章下线或进入回收站时，原收藏暂不出现在个人收藏列表；再次发布或恢复为已发布状态后，原收藏重新出现。
2. 文章下线或进入回收站时，其评论暂不对读者展示；文章再次公开时，未被单独删除的评论重新展示。
3. 单条评论删除后不能恢复。评论只支持纯文字，不支持回复、附件或编辑。
4. 文章中的图片随文章正文展示；文章不可公开时，读者不能通过文章继续查看图片；恢复文章后，图片仍在原位置。
5. 仅文章删除有回收站和恢复入口；从正文移除的图片及单独删除的评论不提供恢复入口。

## 7. 页面与体验要求

| 页面 | 必要内容与操作 |
| --- | --- |
| 首页 / 文章列表 | 最新文章、摘要、作者、标签、搜索入口和翻页 |
| 文章详情 | 标题、作者、图文正文、标签、收藏入口、评论列表和发表评论入口 |
| 搜索 / 标签结果 | 当前搜索词或标签、匹配文章、无结果提示 |
| 注册 / 登录 | 邮箱、昵称、密码等对应表单、错误提示、注册与登录互相跳转 |
| 我的收藏 | 已收藏且仍公开的文章、取消收藏、空状态 |
| 文章管理 | 自己或全站的文章列表、状态筛选、新建与编辑入口 |
| 文章编辑与预览 | 内容填写、图片上传、标签选择、保存、预览、发布、下线和删除 |
| 回收站 | 已删除文章、作者、删除时间和恢复操作 |
| 标签管理 | 标签列表、新增、改名和删除 |
| 用户权限管理 | 注册用户列表、授予和撤销博主权限 |

所有可操作表单应标明必填项，错误要指出具体字段；关键操作完成后应反馈结果。手机和桌面端均可完成阅读、注册、评论及博主的主要写作流程。图片应可填写替代文字，页面主要操作可通过键盘完成。

## 8. 验收场景

1. 访客打开首页，浏览文章详情，使用关键词和标签找到公开文章；草稿、已下线和回收站文章无法被访问。
2. 访客用邮箱、昵称和密码注册，登录后收藏文章，在“我的收藏”中找到它，发表评论，再取消收藏并退出；重复邮箱注册失败。
3. 管理员授予一名注册用户博主权限。两位博主分别写文章，均无法修改对方文章；管理员可以管理双方文章。
4. 博主创建草稿，上传图片、选择标签并预览；读者此时看不到草稿。博主发布后，读者能在列表、搜索和标签结果中找到文章并看到图片与作者。
5. 博主修改已发布文章，再将其下线；读者先看到更新，随后无法访问。原收藏和评论暂不展示，再次发布后恢复展示。
6. 博主删除文章并在回收站恢复；文章返回删除前状态，正文、图片、标签、评论和访问地址保持一致。普通用户不能执行该操作。
7. 评论者删除自己的评论；文章博主删除自己文章下的评论；其他博主不能删除该评论；管理员可以删除全站评论。
8. 管理员撤销一位博主的权限；该用户不能继续管理文章，已发布文章及作者署名仍保留。
9. 首次接触项目的观众按公开说明执行一次启动操作后，可以重复以上主要流程。

上述场景全部通过，即达到本版产品验收标准。
